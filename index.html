Firebase Bağlantı Rehberi

Kendi Firebase projenizi 2 dakikada bağlayın
1
Firebase Konsolu: console.firebase.google.com adresine gidin ve yeni bir proje açın (veya var olanı seçin).
2
Servisleri Etkinleştirin:
  • Authentication: Sol menüden Authentication -> Get Started tıklayın, Email/Password sağlayıcısını etkinleştirin.
  • Cloud Firestore: Sol menüden Firestore Database -> Create Database tıklayın, test modunda başlatın.
3
Config Bilgilerinizi Kopyalayın: Proje Ayarları (Project Settings) -> Genel (General) altından Web Uygulaması (</>) ekleyin ve verilen firebaseConfig objesini kopyalayın.
4
js/firebase-config.js dosyasına yapıştırın: Projenizdeki js/firebase-config.js dosyasını açıp config alanına yapıştırıp kaydedin. Sayfayı yenilediğinizde sağ üstteki gösterge yeşil olacaktır!
